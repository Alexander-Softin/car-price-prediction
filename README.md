# 🚗 AI Car Price Predictor

Интерактивное веб-приложение для прогнозирования рыночной стоимости автомобилей на основе алгоритмов машинного обучения.

## 📌 Описание проекта
Данный проект представляет собой полноцикловое ML-решение (от подготовки данных до деплоя), предназначенное для оценки стоимости подержанных автомобилей на основе их технических характеристик. 

Система позволяет пользователю в реальном времени изменять параметры авто и мгновенно получать прогноз цены, сформированный обученной нейросетью.

## 🚀 Ключевые возможности
* **Интерактивный интерфейс:** Удобные ползунки и поля ввода на базе фреймворка `Streamlit`.
* **Высокая точность:** Модель на базе алгоритма `Random Forest Regressor` достигла показателя **$R^2 = 0.95$**.
* **Автоматизация:** Обработка 8 ключевых признаков (мощность, объем двигателя, габариты, вес и др.).
* **Облачное решение:** Проект развернут в Streamlit Cloud и доступен по прямой ссылке без установки Python.

## 🛠 Технологический стек
* **Язык программирования:** Python 3.11
* **ML-библиотеки:** `Scikit-learn`, `Pandas`, `NumPy`
* **Интерфейс:** `Streamlit`
* **Сериализация:** `Pickle` (формат .pkl)

## 📊 Структура репозитория
* `app.py` — основной файл веб-приложения и логика интерфейса.
* `train_model.py` — скрипт обучения модели и генерации файла .pkl.
* `car_model.pkl` — сохраненные веса обученной модели (Random Forest).
* `requirements.txt` — список зависимостей для корректной работы в облаке.
* `README.md` — документация проекта.
